
# Kubernetes troubleshooting

## Questions & Answers

### If one of 16 instances of a service in Kubernetes falls over once a week due to CPU throttling, how would you diagnose and fix it?

**Key points:**
- Check Grafana metrics for CPU, memory, and GC activity leading up to the crash.
- Look for uneven load balancing or specific heavy requests hitting that particular pod.
- Replicate the issue using a load testing tool on an isolated staging environment.
- Increase logging levels temporarily to catch the culprit if the metrics aren't granular enough.
