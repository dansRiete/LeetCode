
## Questions & Answers

### What is the contract between equals() and hashCode()? What happens to a HashMap if hashCode() always returns 42?

**Key points:**
- The contract requires three properties for `equals()`: reflexivity, symmetry, and transitivity.
- If `hashCode()` always returns the same value (like 42), all elements will fall into the same bucket in a `HashMap`.
- This causes the `HashMap` to degrade into a linked list (or a Red-Black tree after 8 elements, from Java 8 onwards).
- Consequently, the constant `O(1)` time complexity for operations degrades to `O(N)` or `O(log N)`.
