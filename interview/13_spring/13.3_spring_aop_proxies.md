
## Questions & Answers

### What happens if a method A calls method B in the same class, and method B is annotated with @Transactional? Will a transaction open?

**Key points:**
- No transaction will open.
- Spring uses proxies to apply `@Transactional`. The proxy intercepts calls coming from *outside* the class.
- When method A calls method B internally (`this.B()`), it bypasses the proxy entirely, so the `@Transactional` annotation on B is ignored.
