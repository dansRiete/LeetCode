
# Spring Code Review

## Questions & Answers

### What common code smells do you look for in a Spring service code review?

**Key points:**
- **Field injection** (`@Autowired` on fields) instead of constructor injection.
- **Using `double` or `float`** for monetary values instead of `BigDecimal`.
- **Missing `@Transactional`** or missing `rollbackFor = Exception.class` on methods that need atomicity.
- **Using `System.out.println`** instead of a proper Logger (`log.info()`).
- **Loading all records** (`repo.findAll()`) just to filter them in memory, instead of doing `findById()` or a database query.
- **Creating new instances** of expensive beans (like `new RestTemplate()`) inside methods instead of injecting a shared bean.
